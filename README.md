# Boston Sports Data Visualization

A web-based interactive data visualization project focused on the four major Boston sports franchises:

* Boston Celtics
* Boston Bruins
* Boston Red Sox
* New England Patriots

This project uses historical team performance data and interactive charts to explore trends, compare franchises, and visualize championships, wins, losses, and seasonal performance over time.

---

## Features

### Interactive Team Visualizations

* Animated line charts for wins and losses across seasons
* Hover tooltips displaying detailed season statistics
* Smooth chart transitions and drawing animations
* Team-specific styling and branding

### Championship Tracking

* Visualization of championship years for each Boston franchise
* Timeline and comparison views between teams
* Historical trend analysis

### Data-Driven UI

* Dynamic chart generation using JavaScript and D3.js
* CSV driven datasets
* Scalable structure for adding additional teams or statistics
